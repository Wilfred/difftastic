Difftastic's AI policy is based on the [LLVM AI Tool Use
Policy](https://llvm.org/docs/AIToolPolicy.html).

Use any tool you like, but make sure you've read all the code before
creating a pull request. You should be able to discuss any part of
your changes.

Please disclose AI usage in commit messages or pull request
descriptions. A single line is enough, either in the pull request
description:

    Written with an AI coding assistant, then reviewed and tested by hand.

or as a trailer on the commits themselves:

    Co-authored-by: Some AI Assistant <noreply@example.com>

Disclosure helps reviewers know how much scrutiny a change needs, and
it's much less work than discovering it during review.
